## PHREEQC database

`phreeqc.dat` is the database distributed with PHREEQC 3.8.6 by the U.S. Geological Survey. It is included unchanged so that every run uses the same thermodynamic data; see the PHREEQC distribution for its terms.

## Model outputs

The files in `result/` contain inputs, answers, and messages generated by the evaluated models, together with tool results. Use of each model's outputs is also subject to that provider's terms.
